# 赛博祈福

一个离线的 macOS 菜单栏小工具，提供上香、掷圣杯、敲木鱼和盘串四种体验。无需登录，应用不发送网络请求，设置与累计统计保存在本机。仅供娱乐与仪式体验，掷杯结果不预测或保证现实结果。

**下载安装后，点击屏幕顶部菜单栏的火焰图标使用。** 应用没有独立的主窗口，也不会显示常驻 Dock 图标。

## 下载与安装

要求 **macOS 13 或更新版本**。同一个安装包包含 Apple Silicon（M 系列）和 Intel 两种架构，无需分别选择；目前实际运行验证覆盖 Apple Silicon，Intel 仍待实机验证。

1. [下载 0.7.4 macOS 应用 ZIP](https://github.com/HKUSTlsy/cyber-blessing/releases/download/v0.7.4/CyberBlessing-0.7.4-macOS.zip)。也可以打开 [Release 页面](https://github.com/HKUSTlsy/cyber-blessing/releases/tag/v0.7.4)，在 **Assets** 中选择 `CyberBlessing-0.7.4-macOS.zip`。
2. 双击 ZIP 解压，得到 `CyberBlessing.app`。
3. 将 `CyberBlessing.app` 拖到「应用程序」文件夹，然后双击打开。
4. 按下方步骤完成首次打开，之后点击菜单栏的火焰图标即可使用。

普通用户只需下载上述 macOS ZIP。`source.zip` 和 GitHub 自动生成的 `Source code` 是源码；`.sha256` 是可选的校验文件。**使用应用不需要安装 Xcode、Swift，也不需要购买 Apple 开发者会员。**

### 首次打开未公证版本

当前 0.7.4 是 **未公证测试版（Pre-release）**：使用本地 ad-hoc 签名，尚未取得 Developer ID 签名和 Apple 公证。macOS 可能提示「无法验证开发者」或「Apple 无法检查是否包含恶意软件」，并阻止直接打开。这与应用需要注册账号无关。

确认文件来自本仓库的 Release 后：

1. 先双击「应用程序」中的 `CyberBlessing.app`，让系统显示拦截提示，然后关闭提示。
2. 打开「系统设置 → 隐私与安全性」，向下滚动到「安全性」区域。
3. 找到这次应用拦截记录，点击 **「仍要打开」**，按提示进行身份验证。
4. 再次确认 **「打开」**。系统通常会记住该应用的例外，之后可以直接启动；换用新版本时可能需要再次确认。

这是 Apple 提供的单个应用放行方式，无需关闭整个系统的安全检查。不同 macOS 版本的提示文字可能略有差异，详见 [Apple 官方打开说明](https://support.apple.com/zh-cn/102445)。公司或学校管理的 Mac 可能由管理员限制放行。

## 怎么使用

点击菜单栏火焰图标打开面板，通过面板**右上角的仪式菜单**切换功能。

| 功能 | 操作 | 反馈 |
| --- | --- | --- |
| 上香 | 点击「擦火柴，点一炷香」 | 播放点香动画和音效，点燃后开始约 30 分钟倒计时，显示燃香与烟雾。 |
| 掷圣杯 | 点击「掷出圣杯」，之后可「再掷一次」 | 播放抛落动画与木块落地声，显示圣杯、笑杯或阴杯。 |
| 木鱼 | 点击木鱼画面或「敲一下」 | 木槌敲击、播放音效，显示「功德 +1」并累加计数。 |
| 盘串 | 将鼠标放在手串画面内，滚动鼠标滚轮或触控板 | 拇指拨动珠子，滚动越快，拨动越快；支持反向滚动，也可点击「拨一颗」。 |

燃香按真实时间计算：关闭面板或退出应用后计时不会暂停，再次打开会更新剩余时间。想重新看点香动画，可以点击「结束此炷，重新体验点香」提前结束当前香；累计上香次数保留。30 分钟是应用设定的体验时长，并非现实香支的统一燃烧时长。

掷杯尚未落地时关闭面板或切换功能，会取消本次掷杯，不增加次数。落地后保存最近结果。采用简化规则：平面朝上为阳、凸面朝上为阴；一阴一阳为圣杯，两阳为笑杯，两阴为阴杯，每枚杯独立随机。

### 声音、动效和统计

点击面板底部的 **滑杆图标**，进入「设置与统计」：

- 开关音效、调整音量，或开启「减少动态效果」。系统开启减少动态效果时，应用也会遵循。
- 查看累计上香、掷杯、功德和拨珠次数。设置和统计会在重启后保留。
- 点击「清空累计统计…」，再点击「确认清空」。这会清空四项累计次数与最近掷杯结果，保留正在燃烧的香和偏好设置；点击「取消」则保留统计。

再次点击滑杆图标返回仪式。点击底部「退出」关闭应用；只关闭面板不会退出应用。

### 快捷键

快捷键在应用面板打开并获得焦点时使用，并非全局快捷键。

| 快捷键 | 操作 |
| --- | --- |
| `⌘1` / `⌘2` / `⌘3` / `⌘4` | 切换上香 / 掷杯 / 木鱼 / 盘串 |
| 空格 | 在盘串页面拨一颗珠子 |
| `⌘Q` | 退出应用 |

## 常见问题

**打开后没有窗口，是没有启动吗？**

这是菜单栏应用，请查看屏幕顶部的火焰图标并点击。如果菜单栏图标较多，也请检查是否被菜单栏管理工具隐藏。

**盘串滚轮没有反应？**

先切换到盘串，将鼠标移到手串画面内部再滚动。滚动其他位置不会拨珠，也可以用「拨一颗」按钮操作。

**没有声音？**

在设置中检查「播放音效」是否开启、应用音量是否大于零，再检查 Mac 的输出音量和输出设备。

**没有「仍要打开」，或依然打不开？**

先确认已尝试打开解压后的 `.app`，再检查「隐私与安全性」。如果提示「已损坏」或「将损坏你的电脑」，不要一概当作未公证提示：重新从 Release 下载，必要时按 [开发文档中的方法](DEVELOPMENT.md#版本与打包)核对 SHA-256。仍有问题时，请在 [Issues](https://github.com/HKUSTlsy/cyber-blessing/issues) 提供 macOS 版本、芯片类型、应用版本及完整提示文字。

**如何更新或卸载？**

更新时先在面板中退出应用，再用新版本替换「应用程序」中的旧 `.app`，现有统计和设置通常会保留。卸载时先退出，再将 `.app` 移到废纸篓；这不会自动清除本机偏好数据。想先清空统计，可以在卸载前使用设置中的清空按钮。
